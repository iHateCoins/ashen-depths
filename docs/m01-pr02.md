# M01 PR02 — Movement and Camera

## Scope
- Interactive test environment with a camera following the player
- Mouse click / touch tap destination input
- Interruptible straight-line movement with capped per-frame simulation step
- Camera world bounds and adjustable zoom
- Visual destination marker and position diagnostics
- Unit tests for movement arrival, rerouting, and invalid inputs

## Manual checks
1. Open the game in a desktop browser; click around the map and confirm movement.
2. Click a different point while moving; the player should immediately change direction.
3. Test touch taps in mobile landscape.
4. Change browser window size while moving; camera remains centered.
5. Zoom with wheel and +/- keys; pointer destinations still map correctly.
6. Verify no browser scrolling or page gestures when interacting with the game.

## Known limitations
- Decorative pillars are not yet collidable; obstacle avoidance belongs to PR03.
- Character art and walking animations are placeholders.
- No enemies, loot, or extraction.
