# M02 PR01 — Automatic attack prototype

Adds nearest-target automatic attacks to the existing movement playground.
Player does not chase targets and does not require skill buttons. Stationary practice enemies have health bars and disappear on defeat; visual attack pulses show each strike.

## Manual testing
1. Move within range of a red practice enemy; it should automatically take damage.
2. Stay out of range: no attacks should occur.
3. Move between targets: the nearest living enemy should be attacked.
4. Confirm that click/tap movement still works and never automatically chases a target.
5. Test on mobile landscape.
