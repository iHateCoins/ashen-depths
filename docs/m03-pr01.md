# M03 / PR01 — Seeded, continuous dungeon layouts

## Implemented

- Replace the fixed open-floor test playground with a reproducible **eight-chamber, seeded dungeon**.
- Rooms are linked by broad (three-cell) corridors, including **branches** and at least one cycle for backtracking. No room transitions or loading screens.
- Single source of truth for visible floor, wall collisions, A* navigation and wave-spawn path validation.
- Room variants include **Entrance**, **Sealed Cache** and **Deep Chamber** landmarks. These are purely visual until exploration objectives and loot arrive in later M03/M04 PRs.
- Initial player spawn uses the generated entrance, with the existing following camera and click/tap movement.
- Optional `?seed=42` link reproduces the same dungeon across reloads. Otherwise restarting the trial rolls a new seed.
- Preserve the existing three-wave combat trial, Cinder Burst, enemy telegraphs, victory/restart, and iOS update system.

## Manual acceptance

1. Open the installed iPhone web app after merge. It should auto-update and display **M03 / PR01**.
2. Move around the entrance into multiple rooms through corridors; the camera stays continuous.
3. Tap a room behind a wall; character routes through connected passages rather than directly through solid tiles.
4. Navigate past the Sealed Cache and Deep Chamber markers (these are landmarks, not yet interactive).
5. Survive the same three-wave combat trial. Defeat and victory restart both work.
6. Open `https://ihatecoins.github.io/ashen-depths/?seed=42` in Safari and reload; confirm the layout and seed remain identical.
7. In a normal shortcut without a URL seed, restarting the trial generates another dungeon.

## Boundaries of this PR

The **dungeon layout and exploration space are procedural**, but the waves are still the finite M02 training encounter. Room discovery, fog-of-war/minimap, per-room enemy placement, special room objectives, extraction and loot will be added in following PRs. Art remains prototype geometry, with a shared grid ready for hand-painted tiles.
