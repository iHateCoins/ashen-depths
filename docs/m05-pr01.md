# M05 / PR01 — Automatic Active Skill Loadouts

This is the first playable increment of M05 character builds, based on the existing M02 Cinder Burst combat system. It adds options and player-selected auto-casting without manual combat buttons.

## Gameplay
- **Two active skill slots**, with **at most one copy per unique skill ID**.
- **Cinder Burst** is equipped by default, maintaining existing early-game balance.
- New choices available immediately for prototype testing:
  - **Frost Bloom**: 20-damage broad area (140px radius), 170px targeting range, 6-second cooldown.
  - **Ash Lance**: 65-damage focused attack (28px radius), 320px targeting range, 3.5-second cooldown.
- Both new skills auto-target with the same deterministic line-of-sight, cluster targeting and per-skill cooldown rules used by Cinder Burst.
- A new **SKILLS** button opens a touch-friendly two-slot selector with visible skill statistics and equipped state. Combat pauses while the modal is open.
- Skills may be equipped/unequipped only while the entrance camp is still available, mirroring stash withdrawal rules; after departure the loadout may still be inspected but cannot be changed.
- The left HUD now lists each equipped skill and remaining cooldown. Cinder, frost and lance use distinct in-world colors. Skill damage continues to scale with equipment's Spell affixes.
- Loadouts are run-scoped, reset on New Expedition, and not yet persistent character progression. No new stash schema is introduced.

## Acceptance on desktop/iPhone
1. Start a new expedition and tap **SKILLS**. Cinder Burst occupies one of two active slots.
2. Equip Frost Bloom: the second slot fills. Ash Lance cannot be equipped while both slots are occupied.
3. Unequip Cinder Burst, equip Ash Lance, close SKILLS. See both equipped skills auto-fire as enemies enter range.
4. Reach 3+ closely packed enemies: Frost Bloom hits an area; Ash Lance concentrates on a target.
5. Walk far enough from entrance camp or defeat an enemy, return to the skills menu; buttons are disabled for the remainder of that expedition.
6. Exit via waystone or Warden, start New Expedition; equipped skills reset to Cinder Burst.
7. Verify no manual attack buttons, no duplicate skill slots, no save-data migration, and no regressions to extraction, stash, loot or optional objectives.
