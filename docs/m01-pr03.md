# M01 / PR03 — Collision and pathfinding

## Included
- 32px logical navigation grid independent from artwork
- Eight-neighbor A* with corner-cutting prevention
- Line-of-sight waypoint smoothing and blocked-target snapping
- Visible collidable pillars and wall dividers
- Click/tap route replacement, failed-route cancellation, and queued waypoints
- Unit tests for open rooms, detours, unreachable areas, blocked destinations, and corners

## Manual test checklist
1. Click behind a pillar: the player should walk around it rather than through it.
2. Click behind the horizontal dividers: player should route around the ends.
3. Click on a blocked pillar: destination should snap to nearby walkable space.
4. Click a new location mid-route: old route should be discarded.
5. Test multiple zoom levels and mobile taps.
6. Verify the player never enters blocked navigation cells.

## Known limitations
- This is a static collision grid; moving obstacles and dynamic replanning are future work.
- Agent clearance uses blocked tile cells rather than a continuous swept collision shape.
- Hand-painted art and character animations remain placeholders for PR04.
