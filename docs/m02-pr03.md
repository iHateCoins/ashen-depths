# M02 / PR03 — Cinder Burst and combat visibility

## What is implemented
- **Cinder Burst:** A starter automatic area skill (35 damage, 105px splash radius, 250px targeting range, 4s cooldown).
- Skill automatically fires at the most densely grouped visible enemies. No skill button, manual aiming, or player auto-chase.
- Obstacle line-of-sight filtering for both basic strikes and Cinder Burst, including its splash damage.
- A distinct expanding orange cast ring, short-lived damage numbers, and an unobtrusive skill-cooldown HUD.
- Shared enemy death / HP-bar sync for basic attacks and skill damage, preventing double counting.
- Scene-restart reset for health, enemy roster, kill counter, movement, cooldowns, and debug state.
- Logic is a reusable deterministic, Phaser-independent skill module with automated unit tests.

## Acceptance on desktop and iPhone
1. Move near the enemy cluster. **Cinder Burst** should automatically flash and damage nearby enemies.
2. Check the cooldown readout near the bottom-left. The skill fires only when an enemy can be targeted and cooldown has finished.
3. Continue moving while the skill fires, without touching any attack buttons.
4. Walk behind an obstructing wall: attacks must not pass through it.
5. Let enemies defeat you; **RESTART EXPEDITION** should reset HP and repopulate enemies with refreshed cooldowns.
6. Verify portrait and landscape layouts, especially top debug button and bottom skill status.
