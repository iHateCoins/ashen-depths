# M04 PR07 — Post-Warden exploration remains playable

Fixes the player-reported regression where defeating the Warden hides the Sealed Cache interaction even when the player has not opened it.

- Remove boss-completion checks that suppressed optional-objective activation and prompts; only actual death or finalized/saved expedition blocks them.
- Leave discovered extraction waystones available after Warden defeat. Finishing the Warden and extracting at a waystone are now both deliberate options.
- Stop cancelling extraction or hiding its panel merely because the Warden was defeated.
- Keep Warden's FINISH EXPEDITION action accessible until the run is secured.
- Add browser regressions for post-Warden cache/shrine collection and optional waystone extraction.
- Update in-game build label to M04 / PR07.

## Acceptance
1. Defeat the Warden before opening the cache, return to the cache room, kill its guards and use OPEN CACHE; +10 basic attack bonus applies.
2. Visit an unclaimed shrine after Warden defeat while injured; USE SHRINE works once.
3. Post-Warden loot pickup and FINISH EXPEDITION remain available.
4. Discover a waystone after defeating the Warden; EXTRACT NOW channels, then persists worn/carried loot normally.
5. Nothing saves automatically on Warden death; death and finalized-run guards still prevent interactions.

Note: stash backup/export was originally considered for PR07, but intentionally deferred to a separate persistence PR to minimize risk to player saves. Browser tests have been added but not executed in this connector-only environment. Review CI and manual iPhone tests before merge.
